Designer Handoff Checklist

All cards, frames, and checklists must use Figma Auto Layout (`Shift + A`) for dynamic screen scaling.

Run the Stark plugin to verify high contrast across Green, Amber, and Red background fills.

Verify all interactive buttons have at least 12px top/bottom padding to guarantee physical tap targets.

Keep the audio pill persistently fixed in the top right header across all states.
