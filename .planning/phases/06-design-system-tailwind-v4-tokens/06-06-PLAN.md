<objective>
Prove the D-15 Figma-extraction-then-screenshot-diff mechanism end-to-end on ONE real, already-shipped
component (Button) before the rest of this rework repeats it ~15 more times across a much larger
component set. This is the phase's tracer: it touches every layer the phase will touch again (Figma MCP
read, CVA restyle, DESIGN.md provenance, `next build` verification, visual comparison) on the smallest
possible real slice, so an architectural dead-end in the mechanism itself is caught after one task, not
after ten.

Purpose: Phase 6's original 5-plan execution was rejected wholesale because "giving Figma links did
nothing" — components were built without ever really inspecting the node's real spacing/radius/shadow/
type values (06-CONTEXT.md `<specifics>`). D-15 exists specifically to break that pattern. This plan is
where the mechanism gets proven for real, on Button, which already has a working file/variant-API
skeleton and four concrete Figma node IDs to reconcile against (D-12).
Output: A Figma-verified `button.tsx` (variant set may differ from the old primary/secondary/tertiary/
critical names) + an updated `button.DESIGN.md` citing the exact node(s) it was built from.
</objective>
